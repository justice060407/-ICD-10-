# 新手友好改进建议

这份评审面向"人工智能专业本科生第一次接触医疗 NLP"的场景。当前项目已经有完整链路、20 条虚构病历、脱敏审计、实验自检和 Docker 交付，基础很好；下一步重点是把学生的第一次体验做得更顺。

## 已经做得好的地方

| 模块 | 现状 | 对新手的价值 |
|---|---|---|
| 全链路 | 合成病历 -> 脱敏 -> NER -> 结构化 -> ICD -> LoRA/SFT -> QA | 学生先建立整体地图，再分模块学习 |
| 数据 | 20 条虚构病历覆盖多个科室，含金标准 ICD | 避免真实病历合规风险，也能做评测 |
| 脱敏 | 有审计日志、残留风险扫描、代理值命名空间 | 把"合规"变成可运行、可检查的工程动作 |
| 实验 | lab0 到 lab7 有指导书和自检脚本 | 学生知道每一步交什么、怎么验收 |
| Docker | 标准库 base 镜像，默认不依赖 GPU | 机房、笔记本、断网环境都能跑核心实验 |

## 课堂建议

第一节课不要直接讲 LoRA。建议先让学生跑 `docker compose up viewer`，打开预览页后只问三个问题：

1. 哪些字段被脱敏了，哪些正文没有动？
2. NER 高亮里有没有明显抽错的实体边界？
3. 医疗问答为什么必须保留就医提示？

这三个问题能把合规、信息抽取和安全边界一次讲清。学生有了直觉后，再进入 lab1 到 lab7，会轻松很多。
