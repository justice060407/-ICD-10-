## 二、过程性数据采集（对接智能评估链）

### 2.1 采集点设计

| 采集点 | 数据来源 | 频次 | 敏感级别 |
|---|---|---|---|
| 实验交付物 | 学生提交的 `out/` 目录 | 每实验 1 次 | 低（全为合成数据） |
| 管道运行指标 | `deid_report.json` / `icd_report.json` / `ner_report.json` | 每实验 1 次 | 低 |
| 助教交互日志 | `tutor_interactions.jsonl` | 实时 | 低（仅学号，不含 PII） |
| 合规闭卷测验 | 课堂测验成绩 | 每 2 周 1 次 | 中（含成绩） |
| 期末路演评分 | 教师 + 企业导师评分表 | 1 次 | 中 |

> 说明：所有采集点均不含真实个人信息，因此**可直接进入粤教链存证流程**，
> 无需额外的伦理审批。这一点要在给评审的说明里讲清楚，是本设计相对
> 真实教学数据的显著优势。

### 2.2 交互日志字段（`tutor_interactions.jsonl`）

| 字段 | 类型 | 说明 |
|---|---|---|
| `student_id` | str | 学号哈希值，不用真实学号以外的标识 |
| `question` | str | 学生提问原文 |
| `backend` | str | rule / deepseek-r1 / local-lora |
| `retrieved` | list | 命中的合成病历编号 |
| `raw_len` | int | 模型原始输出长度 |
| `guarded` | bool | 是否被安全护栏介入 |
| `answer` | str | 最终呈现给学生的回答 |

**可直接计算的指标**：

- `护栏介入率 = guarded 为 True 的比例` —— 反映模型本身合规输出能力
- `就医提示覆盖率` —— 硬性指标，要求 100%
- `检索命中率 = retrieved 非空的比例` —— 反映提问与教学病例库的贴合度

实测基线（规则后端，20 条评测问答）：护栏介入 20/20，就医提示覆盖率 **100%**。

### 2.3 能力达成度计算

每个能力单元 `CU-CM-xx` 的达成度：

```
达成度(CU) = Σ(评分量规得分 × 权重) / Σ(满分 × 权重)
```

判定规则：

| 达成度 | 判定 | 处置 |
|---|---|---|
| ≥0.85 | 已掌握 | 进入下一单元 |
| 0.60–0.85 | 基本掌握 | 记录为待巩固 |
| <0.60 | 未掌握 | 计入"能力缺失率"分子 |

## 三、三级预警（对接红黄蓝机制）

| 级别 | 触发条件 | 72 小时内动作 |
|---|---|---|
| 🟡 黄牌 | 单个能力单元达成度 <0.60 | 追加 1 次针对性练习 |
| 🟠 橙牌 | 某次实验的能力缺失率 >25% | 调整下一轮实验难度或补讲 |
| 🔴 红牌 | 整体能力缺失率 >40%（对齐总项目阈值） | 触发模块重构，重写该实验任务书 |

> 总项目阈值为"岗位能力缺失率超过 40% 触发红牌预警"。本课程沿用同一阈值，
> 保证数据可以汇总进总项目的预警系统。

## 四、给 Shapley 值模型的数据准备

总项目要用 Shapley 值量化"各能力单元对就业质量的贡献度"。
本课程能提供的结构化输入：

```
学生 × 能力单元 × 达成度矩阵  →  对齐就业结果（起薪、对口率）
```

建议补充采集（需与项目负责人确认）：

- 学生实习去向与岗位名称
- 起薪区间（分档而非精确值，降低敏感度）
- 企业导师评价（1–5 分）

> 提示：如果只用本门课 30 人的样本，Shapley 值的估计会很不稳定。
> 建议向负责人申请把三个微专业群的样本合并建模，样本量才够。
