## 场景 A · 你的笔记本：先把"Docker 化"这件事亲眼看到

### A-1 装 Docker Desktop（约 10 分钟，需重启一次）

1. 下载地址：`https://www.docker.com/products/docker-desktop/`
2. 安装时勾选 **"Use WSL 2 instead of Hyper-V"**（默认勾选，别取消）
3. 安装完成后重启，启动 Docker Desktop，等到左下角状态变绿 `Engine running`

验证：
```powershell
docker version
docker run hello-world
```

> 如果 `docker version` 报 `error during connect`，八成是 Docker Desktop 还没启动完，
> 等状态绿了再试；还不行就在 Docker Desktop 里点 Troubleshooting → Restart。

### A-2 构建并运行课程镜像

在 PowerShell 里进入项目目录：

```powershell
cd C:\Users\19354\WorkBuddy\2026-09-21-18-51-41\clinical-llm-course

# 构建（约 1-2 分钟，因为不装任何 pip 包）
```

## 场景 B · 学校机房 3090（24GB）：跑完整的实验 5

### B-0 先确认机房到底有什么

```powershell
nvidia-smi
python --version
docker version 2>$null; if ($?) { "有Docker" } else { "无Docker" }
```

机房大概率**没有 Docker**，而且不一定能联网。所以下面按"无 Docker + 手动装环境"来写，
这反而是最稳的做法。

### B-1 建虚拟环境装 torch（约 15 分钟，需联网）

```powershell
cd C:\Users\19354\WorkBuddy\2026-09-21-18-51-41\clinical-llm-course

python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3090 是 Ampere，CUDA 12.1 兼容
pip install torch --index-url https://download.pytorch.org/whl/cu121
pip install transformers peft datasets accelerate
```

> 若 PowerShell 禁止执行脚本：
> `Set-ExecutionPolicy -Scope Process RemoteSigned`，然后重新激活。

验证显卡可用：
```powershell
python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```
期望：`True NVIDIA GeForce RTX 3090`

### B-2 先把数据准备好（无显卡也能做）

```powershell
python src\run_pipeline.py --key "本课程密钥"
```

### B-3 跑 LoRA 微调

```powershell
python src\train_lora.py --data out\sft_train.jsonl --model Qwen/Qwen2.5-1.5B-Instruct --epochs 3 --rank 16 --lr 2e-4 --out out\lora
```

**3090 24GB 预期**：约 15–25 分钟，显存占用峰值约 12–16GB。

首次运行要下载模型权重（约 3GB），如果机房下载慢，可以在你自己的笔记本上先下好，
用下面两条命令导出过去：

```powershell

huggingface-cli download Qwen/Qwen2.5-1.5B-Instruct --local-dir models\Qwen2.5-1.5B-Instruct
# 拷整个 models 目录到机房，然后改 --model 指向本地路径
python src\train_lora.py --data out\sft_train.jsonl --model models\Qwen2.5-1.5B-Instruct --epochs 3
```

### B-4 如果你的笔记本（5060 8GB）也要跑

RTX 5060 是 Blackwell 架构，**torch 需要 2.7 及以上**才支持：

```powershell
pip install --upgrade torch --index-url https://download.pytorch.org/whl/cu128
python src\train_lora.py --data out\sft_train.jsonl --model Qwen/Qwen2.5-0.5B-Instruct --epochs 3 --rank 8 --4bit
```

用 0.5B + 4bit 是为了塞进 8GB 显存。如果 `bitsandbytes` 在 Windows 上装不上，
去掉 `--4bit` 直接跑 0.5B 全精度，8GB 也够。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `docker build` 卡在下载 python 镜像 | 网络慢或被墙 | 配国内镜像加速器：Docker Desktop → Settings → Docker Engine，加 `"registry-mirrors": ["https://docker.m.daocloud.io"]` |
| 容器里 `out/` 是空的 | 卷挂载路径不对 | 确认在 compose 所在目录执行；Windows 下路径用 `/c/...` 形式之前先试相对路径挂载 |
| `torch.cuda.is_available()` 为 False | 装成了 CPU 版 torch | 重新用 `--index-url .../cu121` 装，别用默认源 |
| 机房不能联网 `pip` | 内网策略 | 在本机 `pip download -d wheels torch ...` 打包，拷过去 `pip install --no-index --find-links=wheels torch` |
| 训练时显存爆了 | batch 太大或序列太长 | 换 `--4bit`，或改 0.5B 模型；`train_lora.py` 里 `per_device_train_batch_size` 已经是 1 |
| 中文输出乱码 | PowerShell 控制台编码 | 每条命令前先执行 `chcp 65001`，或用 `-X utf8` 参数 |
