## 每个实验的统一结构

每份指导书都包含五段，**按顺序做，别跳**：

1. **你要做什么** —— 一句话说清任务
2. **动手步骤** —— 可复制的命令 + 预期看到的输出
3. **验收标准** —— 老师按这个打分，先自己对着检查
4. **常见坑** —— 前几届踩过的，别重复踩
5. **思考题** —— 写进实验报告

---

## 三条不能碰的红线（一票否决）

1. **禁止使用真实患者数据。** 任何来源的真实病历都不行，哪怕是"我亲戚的"。
2. **禁止关闭残留扫描。** 脱敏管道里的 `--no-audit` 参数是给你理解风险和对照组用的，
   正式提交时**必须带着审计日志**。
3. **禁止输出没有就医提示的医疗回答。** 实验 6 的所有回答末尾必须有就医声明。

违反任意一条，本课程成绩直接不及格，不看其他部分。

## 交作业的方式

每个实验交一个文件夹，命名 `学号_labN/`：

```
学号_lab1/
├── 源文件（.py / .jsonl）
├── out_labN/            ← 运行产出，原样保留
├── 实验报告.md           ← 含思考题答案
└── SELFCHECK.txt        ← tools\check_lab.py 的输出
```

最后一步别忘了：

```powershell
python tools\check_lab.py --lab 1 --out out_lab1 > SELFCHECK.txt
```

## 采集点说明（给任课教师 / 研究生助教）

每个实验会自动留下三类过程数据，**全部不含个人信息**，可直接进存证流程：

| 采集点 | 落到哪个文件 |
|---|---|
| 管道运行指标 | `out_*/deid_report.json`、`ner_report.json`、`icd_report.json`、`sft_report.json` |
| 学生交付物 | `学号_labN/out_labN/` 整个目录 |
| 助教交互日志 | `out/tutor_interactions.jsonl` |

这是本课程第一轮 DBR 迭代的数据源，学生不用额外操作，正常跑就会留下。
