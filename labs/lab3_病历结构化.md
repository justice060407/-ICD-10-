# 实验 3 · 病历结构化

**学时**：2 学时 | **性质**：短实验 | **对应岗位**：医疗 NLP 工程师
**对应课程目标**：CO3 | **交付**：`schema.json` + 20 条结构化结果 + 字段完整率报告

---

## 一、你要做什么

把自由文本的病历，转成**能直接进数据库的规范 JSON**。

这是整条链路上最不起眼、但在工业界最赚钱的一环。原因很简单：
医院的信息系统大多是关系型数据库，一份 PDF/Word 格式的病历，
在系统眼里就是一堆无法查询的字符串。**结构化之后它才变成了资产。**

---

## 二、学时短但别轻视

只有 2 学时，因为代码量不大。但**设计决策比代码重要**：

- 这个字段要不要建两层？
- 单位是带在值里还是单独一个字段？
- 缺失了该写 `null`、`""` 还是不写这个 key？

这些决定会直接影响下游能不能用。**你的评分主要看 Schema 设计得合不合理。**

### 步骤 2：先设计 Schema，再写代码

**先不要写代码。** 拿一张纸，把这 6 类信息画成树：

```
record
├── basic      基本人口学：性别、年龄段（注意不是具体年龄）、科室
├── admission  入院信息：入院日期（已脱敏）、住院天数区间
├── chief      主诉：原文 + 抽取出的关键症状列表
├── diagnosis  诊断：主要诊断、其他诊断列表、ICD-10 编码
├── exam       检查：结构化后的检验项列表
└── medication 用药：药物名、剂量、频次
```

对着这个树，回答三个问题（写进报告）：

1. **`exam` 里的检验值怎么存？**
   `{"血糖": "11.8mmol/L"}` 还是 `{"name":"空腹血糖","value":11.8,"unit":"mmol/L"}`？
   前者写起来快，后者才能做"糖化血红蛋白 > 9%"这样的查询。**你选哪个，为什么？**

2. **年龄为什么用年龄段而不是具体值？**
   回头看实验 1 的"准标识符"概念。

3. **主要诊断和初步诊断是一回事吗？**
   看 `sections.初步诊断` 的格式：`"2型糖尿病伴多个并发症；糖尿病周围神经病变；..."`
   分号分隔，第一个是什么？这在病案管理里叫什么？

### 步骤 3：实现抽取

输入是 `out/records_deid.jsonl`（脱敏后的），每条的 `sections` 是六个文本段。

至少要抽出来的字段（**评分的最低要求**）：

| 字段 | 来源段 | 抽取方式提示 |
|---|---|---|
| 主诉原文 | `主诉` | 直接取 |
| 症状列表 | `主诉`+`现病史` | 用实验 2 的 `SYM` 实体结果 |
| 生命体征 | `查体` | 正则找 `T/P/BP` 后的数字 |
| 检验项 | `辅助检查` | 按 `，` 切，找带单位的值 |
| 主要诊断 | `初步诊断` | 分号前第一段 |
| 其他诊断 | `初步诊断` | 分号后剩余段 |

### 步骤 4：算字段完整率

这是本实验的核心交付指标：

```
字段完整率 = 成功抽出的字段数 / (记录数 × 字段总数)
```

自己写个统计，**要求 ≥ 90%**。不到 90% 的话，报告里说明缺的是哪些、
为什么抽不出来（通常是原文格式太多样）。

## 四、验收标准

| 检查项 | 权重 | 达标条件 |

| Schema 设计 | 35% | 至少 6 个一级字段，嵌套合理，单位处理有明确理由 |

| 异常值处理 | 15% | 对缺失 / 格式异常的输入有兜底，不会抛异常终止 |

## 五、常见坑

| 坑 | 说明 |
|---|---|
| 把整段文本塞进一个字段 | 那不叫结构化，叫换了个容器 |
| 数值存成字符串 | `"11.8"` 没法参与排序和统计，下游做不了查询 |
| 单位混着写 | `9.4%` 和 `9.4` 同时存在会让所有分析失效 |
| 缺失字段不写 | 下游 `dict['key']` 直接 KeyError。约定统一：缺失一律 `null` |
| 直接 `float()` 强转 | 遇到 `"未查"`、`"—"` 就崩。务必先 try/except 兜底 |

## 六、思考题

1. 你选"扁平结构"还是"嵌套结构"？各自的适用场景是什么？
   （提示：想想下游是做 SQL 查询还是做 JSON 检索）
2. 如果医院要求支持"检索所有糖化血红蛋白 > 9% 且用过二甲双胍的患者"，
   你的 Schema 支持吗？不支持的话要怎么改？
3. 结构化会**丢失**什么信息？（提示：原文的语序、否定词、程度副词）
   这些丢失的信息在什么任务上会造成严重后果？
4. 你的字段完整率 90%，剩下 10% 缺失的是随机分布还是集中在某类病历上？
   如果是后者，说明你造了一个**系统性偏见**——这在真实业务里意味着什么？

> 第 4 题是工业界真实教训：一个在某家医院 95% 准确率的系统，换到基层医院掉到 60%，
> 往往就是因为抽取规则是按三甲医院的书写习惯写的。
